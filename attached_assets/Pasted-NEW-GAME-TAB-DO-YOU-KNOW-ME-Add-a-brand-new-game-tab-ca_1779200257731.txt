NEW GAME TAB: “DO YOU KNOW ME?”

Add a brand-new game tab called “Do You Know Me?” into the Dordor Games platform.

CORE CONCEPT:
This is a fast-paced social party game about testing how well friends know the current “Asker.”

The game is played entirely verbally in real life. Phones are ONLY used for:
- joining the room
- browsing questions
- selecting categories
- tallying points
- rotating rounds

No typing answers.

ROOM SYSTEM:
- Same existing multiplayer room system.
- Players join using a 5-digit room code.
- Lobby supports nicknames/avatars.
- Host/Admin can start the game once everyone joins.

GAME LENGTH:
Before starting:
Admin selects:
- QUICK GAME = first to 3 points
OR
- LONG GAME = first to 10 points

ROUND STRUCTURE:
Each round has ONE “Asker.”

The Asker is the person answering the questions indirectly while others try to prove they know them.

Example:
Question:
“What bone did I break?”

Other players verbally yell answers.

The Asker manually decides who answered correctly first.

Then the Asker taps that player’s name to award them +1 point.

After the round:
Admin can manually choose the next Asker.

Do NOT auto-rotate.

PLAYER SCORING UI:
The Asker sees all player nicknames in large clickable glowing cards.

Example:
AHMED [2]
LAILA [1]
YOUSEF [0]
SARA [2]

Tapping a player:
+1 point

Tiny undo button beside each player card.

When a player reaches:
- 3 points in Quick Mode
OR
- 10 points in Long Mode
they win.

QUESTION SYSTEM:
This is the HEART of the experience.

Questions are uploaded through Excel/CSV admin upload.

Each question belongs to a category.

Example categories:
- Love
- School
- Health
- Childhood
- Habits
- Secrets
- Favorites
- Family
- Chaos
- Embarrassing
- Relationships

TOP THIRD OF SCREEN:
This should feel like:
Reuters terminal meets Pokédex meets anime database scanner.

The top third contains:
A horizontally scrolling QUESTION NEWSREEL.

Questions move left ↔ right like a ticker/news terminal.

The Asker can swipe horizontally through questions smoothly.

Examples:
- “Which city did I secretly hate?”
- “What bone did I break?”
- “What age did I fail my driving test?”
- “What food makes me sick?”
- “Which year did I travel to Turkey?”
- “What was my worst haircut?”

Below that:
A THINNER CATEGORY NEWSREEL.

Also horizontal.

Categories scroll left ↔ right.

When tapping a category:
Filter questions instantly.

The searching/browsing mechanic must feel FUN and addictive.

This is NOT boring dropdown menus.

It should feel:
- tactile
- swipe-heavy
- stylish
- playful
- like browsing classified anime files
